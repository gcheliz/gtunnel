CLI

One command per tunnel.

Declare it, share it, or run it on the fly. Ctrl+C or a TTL closes it.

ACCESS
gtunnel add db my-vm:5432 -s
PUBLIC
gtunnel expose web 3000 -s
ON THE FLY
gtunnel run my-vm:5432 --ttl 30m

Public mode needs a relay once per account: gtunnel relay up --managed-zone my-dns-zone.

MCP

Ask your agent. It opens the tunnel.

gtunnel mcp is built into the binary. Works with Claude Code, Gemini CLI and Claude Desktop.

QUICK START

Install, check, connect.

Needs the Google Cloud SDK.

# 1 · install
$ cargo install --git https://github.com/gcheliz/gtunnel

# 2 · check
$ gtunnel init
$ gtunnel doctor

# 3 · connect
$ gtunnel add db my-vm:5432 --local-port 15432 -s
$ psql -h localhost -p 15432
