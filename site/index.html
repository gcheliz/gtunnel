Use it

IN TO YOUR VPC

Reach a private VM port from localhost, through IAP.

  • No public IP
  • Your Google login
  • Restarts on its own
Access and jump tunnels in the guide 
$ gtunnel add db my-vm:5432 --local-port 15432 -s
$ psql -h localhost -p 15432
OUT TO THE INTERNET

Put localhost:3000 on an HTTPS hostname, without opening a port.

  • Managed certificate
  • Sign-in optional
  • Relay has no public IP
Public tunnels in the guide 
$ gtunnel relay up
$ gtunnel expose web 3000
  https://web.example.com
ON THE FLY

Need it for five minutes? Just run it.

One command opens a tunnel; Ctrl+C closes it. Nothing to set up, nothing left behind.

# prints the local port
$ gtunnel run my-vm:5432
# stops itself after 30 minutes
$ gtunnel run my-vm:5432 --ttl 30m
# a throwaway HTTPS address
$ gtunnel run --public 3000
  • Picks a free port
  • Cleans up on crash
  • Visible in list and the dashboard

How it works

Access

  1. 1Your clientpsql connects to localhost:15432.
  2. 2gtunnelA supervised gcloud child carries the bytes.
  3. 3IAPChecks your Google identity at the edge.
  4. 4my-vmAnswers on 5432. No public IP, ever.

Public

  1. 1VisitorOpens https://web.example.com.
  2. 2Cloud DNSResolves to the load balancer.
  3. 3HTTPS LBTerminates TLS; a host rule picks the tunnel.
  4. 4Relay VMForwards into the reverse tunnel.
  5. 5localhost:3000Your service answers.
