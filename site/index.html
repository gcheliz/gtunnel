CLI

One command per tunnel.

Two modes, each persistent or ephemeral. Ctrl+C or a TTL closes an ephemeral one.

ACCESS
gtunnel add db my-vm:5432 -s
EXPOSE
gtunnel expose web 3000 -s
EPHEMERAL
gtunnel run my-vm:5432 --ttl 30m

Expose mode needs a relay once per account: gtunnel relay up --managed-zone my-dns-zone.

MCP

Ask your agent. It opens the tunnel.

gtunnel mcp is built into the binary. Add it to your client's config and it can list, start, stop, run, add, delete, rename, move and expose tunnels for you.

QUICK START

Install, check, connect.

Needs the Google Cloud SDK.

# 1 · install
$ cargo install --git https://github.com/gcheliz/gtunnel

# 2 · check
$ gtunnel init
$ gtunnel doctor

# 3 · connect
$ gtunnel add db my-vm:5432 --local-port 15432 -s
$ psql -h localhost -p 15432
